# AIAgentgaokao

This repository contains two applications:

- [`GaoKaoAgent/`](GaoKaoAgent/) - the multi-agent Gaokao application and its project documentation.
- [`smartlife-agent/`](smartlife-agent/) - the imported SmartLife agent application.

Local virtual environments, API credentials, runtime conversation data, and Chroma indexes are excluded from version control. Use each application's example configuration file to create local credentials.
